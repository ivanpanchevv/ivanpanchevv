## Ivan Panchev

Applied Computer Science student at Karel de Grote University of Applied Sciences
in Antwerp, heading into my final year. Most of my time goes into Java and Spring,
with a growing amount in Swift and embedded C.


### Projects

| | |
| --- | --- |
| [**metal-detector-game**](https://github.com/ivanpanchevv/metal-detector-game) | Bare-metal AVR C on an ATmega328P. A joystick-controlled treasure hunt played over a serial terminal, with buzzer proximity feedback and hand-written `led`, `button`, `adc`, `usart`, `display` and `buzzer` drivers. No Arduino framework. |
| [**devicestore**](https://github.com/ivanpanchevv/devicestore) | Spring Boot storefront — Thymeleaf, JPA, Spring Security, a webpack frontend and a Dockerised Postgres, with MVC and API integration tests. |
| [**ludus-romanus**](https://github.com/ivanpanchevv/ludus-romanus) | JavaFX implementation of Ludus Latrunculorum, the Roman strategy game, built on an MVP architecture with a rule-based AI opponent. |
| [**BrikksGame**](https://github.com/ivanpanchevv/BrikksGame) | The board game Brikks in a terminal — block placement with gravity, scoring, and ANSI colour. Plain Java, no dependencies. |
